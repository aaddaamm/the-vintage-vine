# The Vintage Vine

Landing page for The Vintage Vine, a source for hard-to-find props, set
dressing, specialty pieces, large-scale items, and wardrobe for film and
television productions.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

The project is a standard Next.js application configured for Vercel.
